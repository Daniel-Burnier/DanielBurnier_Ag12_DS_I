# Meus Sites Favoritos

Projeto desenvolvido em HTML para armazenar e acessar sites favoritos.

## Tecnologias utilizadas

* HTML5

## Sites incluídos

* YouTube
* Netflix
* Google
* Deezer
* GitHub

## Como executar

1. Baixe os arquivos do projeto.
2. Abra o arquivo `index.html` em qualquer navegador.
